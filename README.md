# lightNIIng

**NeuroImaging Infrastructure at the speed of light.**

Source for [lightniing.org](https://lightniing.org): a static, Markdown-driven site
built with Bun. Each section (`spatial_processing/`, `denoising/`, `web_apps/`, …)
is a folder with a `README.md`; `site.config.ts` lists sections, summaries, tags
and the proven-tools index. Team profiles live in `teams/<slug>/about.md`.

```bash
bun install        # also sets core.hooksPath=.githooks (pre-commit type-checks)
bun run dev        # live-reload server at http://localhost:5173
bun run build      # emit dist/
bun run preview    # build, then serve dist/
bun run typecheck
bun test
```

Pushes to `main` type-check, test, build and deploy `dist/` to GitHub Pages
(`.github/workflows/deploy.yml`).

## Figures

Benchmark charts are TSV files rendered to SVG at build time, inserted with:

```md
<!-- figure-tsv: benchmark.tsv -->
```

Metadata comments: `# type` (`horizontal` | `vertical` | `line`), `# title`,
`# subtitle`, `# source` (rendered as a "Benchmark source" link), `# unit`.
A trailing `*` on a row label draws it in the accent color. Examples:
`examples/figure-*.tsv`.

Conceptual illustrations are generated by `scripts/build-*-illustration.ts`
(e.g. `bun run scripts/build-meica-illustration.ts`).
